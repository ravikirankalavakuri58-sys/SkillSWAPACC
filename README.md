# SkillBridge Live — Multi-File Frontend

Organized across separate files for clean maintenance:
- `index.html` — Markup structure, navigation tabs, AI Study Assistant drawer, and Learning Wallet modal
- `css/styles.css` — Font stack, scrollbar utilities, and transition animations
- `js/data.js` — Goals, trainers, live classes, offline workshops, peer pods, translations, and state persistence
- `js/zip-builder.js` — Client-side ZIP archive builder for the Learning Wallet reward download
- `js/skillgap.js` — AI SkillGap analyzer, personalised learning roadmap, streaks, and project progress
- `js/marketplace.js` — Live class filtering, ₹0–₹199 seat booking, recordings, trainer comparison, and reviews
- `js/community.js` — Doubt Q&A thread, notes/resources, offline RSVPs, peer pods, and skill exchange
- `js/assistant.js` — AI Study Assistant explanations/practice prompts and Learning Wallet modal controls
- `js/app.js` — Tab navigation, language switching, toast notifications, KPIs, and initialization
